## Dynasty Helper Competitive Research (Deep Dive)

**Context:** Taylor asked for deep research on Dynasty Helper's PAR-based valuation system (Reddit post: r/DynastyFF).

**What They Built:**
- **Scale:** 6.5M Sleeper users discovered → 250K active dynasty leagues
- **Method:** Calculate Points Above Replacement (PAR) for standard league, then adjust baseline values by PAR ratio for any custom league
- **Formula:** `league_value = baseline_value × (league_PAR / baseline_PAR)`
- **Data:** Daily trade scraping from 250K leagues (millions of trades)
- **Infrastructure:** Likely PostgreSQL + Redis caching, batch processing overnight

**Their Strengths:**
1. Massive dataset (250K leagues >> anyone else)
2. True league customization (handles ANY scoring/roster format, not just multipliers)
3. Transparency (full PAR methodology public → builds trust)
4. Free (no paywall → faster growth)
5. First mover in league-specific valuation space

**Their Weaknesses:**
1. Single source (only trade data, no expert rankings/ADP/projections)
2. Dynasty-only (can't serve redraft, misses 60% of market)
3. Daily lag (batch processing, stale for 24h after breaking news)
4. No portfolio features (single league focus)
5. Computationally expensive (custom league PAR takes ~1 second)
6. Cold start problem (new leagues have no trade history)

**TitleRun Competitive Position:**

We're AHEAD in:
- ✅ Multi-source valuation (10 sources > 1)
- ✅ Real-time updates (not daily batch)
- ✅ Dynasty + Redraft support
- ✅ Portfolio view (multi-league)
- ✅ Platform diversity (Sleeper + ESPN + Yahoo)

They're AHEAD in:
- ❌ League-specific customization (we only have format multipliers)
- ❌ Trade database size (250K leagues vs none)
- ❌ Public searchable trades (we don't have this yet)

**Recommendations from Research:**
1. **Add PAR layer in Phase 2** (May-Jun 2026) - Layer PAR adjustments on top of our Bayesian baseline
2. **Scale trade database to 250K+ leagues** (Phase 2-3) - Match their data advantage
3. **Partial transparency** - Explain PAR, keep 10-source weights proprietary

**Bottom Line:** Dynasty Helper has ONE killer feature (league-specific PAR). TitleRun has EVERYTHING ELSE. Adding PAR in Phase 2 closes their advantage while maintaining our moat.
